SIMORA — unggah file XLS rincian realisasi hasil export SIPD. Spreadsheet hanya dipakai sebagai database; semua proses dilakukan dari halaman ini.

Kembali ke Dashboard

Pilih file XLS

Gunakan file rincian realisasi (punya kolom "Tgl Bukti"), bukan file rekap ringkasan. File XLS dari SIPD bisa langsung diunggah apa adanya, tidak perlu diubah ke CSV.

Klik untuk memilih file, atau seret ke sini
Format .xls dari export SIPD

Yang terjadi saat import

  1. Transaksi masuk ke Form_Input_Realisasi — satu tempat terpusat untuk semua bulan.
  2. Transaksi yang sudah pernah diimport dilewati otomatis, jadi file yang sama tidak terhitung dobel.
  3. Pagu Master_Kegiatan ikut disinkronkan dari kolom Pagu di file XLS.
  4. Rekap_Realisasi_Triwulanan digenerate ulang, lalu Dashboard langsung ikut ter-update.
